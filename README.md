## Design Approach

The visual direction is built around a few core principles:

- A restrained dark palette with purposeful blue accents.
- Clear typography, spacing, and content hierarchy.
- Consistent styling across sections and components.
- Responsive layouts designed for different screen sizes.
- Animation used to enhance the experience rather than distract from it.

The project uses a straightforward frontend structure, keeping HTML, CSS, and JavaScript in separate files.
